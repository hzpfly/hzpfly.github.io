# VeighNa 是什么
  - 一套用 Python 写交易系统的“底座”。它把累活都做好了：连券商/交易所、收行情、下单、存数据、桌面界面、回测框架。你只需要写“什么时候买、买多少”的策略逻辑。
  - 开源、模块化，Python ≥ 3.10，目前版本 4.5.0。

  心脏：MainEngine + EventEngine
  - vnpy/event/engine.py 的事件引擎就是一个邮箱：谁都可以往里投事件，谁关心就订阅。
  - vnpy/trader/engine.py:89 的 MainEngine 是总控：装接口、装模块、发指令。它自带两个引擎 —— LogEngine（日志）和 OmsEngine（engine.py:375，订单管理系统）。
  - OmsEngine 在内存里存着最新的一张快照：行情、委托、成交、持仓、资金、合约。想查当前价格就问它，不用去问交易所。

  接口层：Gateway
  - vnpy/trader/gateway.py 的 BaseGateway 是适配器基类。一个券商/交易所写一个子类，把它的私有协议翻译成 vnpy 的通用对象。
  - 行情和回报走事件进系统：tick → EventEngine → OmsEngine → 你的策略。

  通用语言：数据对象
  - vnpy/trader/object.py：TickData（逐笔）、BarData（K 线）、OrderData、TradeData、ContractData 等。
  - vnpy/trader/constant.py：方向（LONG/SHORT）、开平（OPEN/CLOSE）、状态（ALLTRADED 等）、交易所。

  功能模块：App
  - vnpy/trader/app.py 的 BaseApp + BaseEngine 是插件格式。CTA 策略、价差、组合、数据录制、风控都是这种插件，装进 MainEngine 就能用，还自带 UI 窗口（PySide6 +
   pyqtgraph）。

  数据从哪来
  - database.py 定义数据库接口，具体实现是独立包（如 vnpy_sqlite）；datafeed.py 是在线行情服务接口；utility.py 里有 load_bar_data、ArrayManager（K
  线序列与指标计算）。

  AI 量化：vnpy.alpha（4.0 新增）
  - 三条腿：dataset（把行情变成因子特征，内置 Alpha158/Alpha101）→ model（Lasso / LightGBM / MLP 训练预测）→ strategy（回测与实盘）。
  - alpha/lab.py 的 AlphaLab 是本地数据/数据集/模型仓库，相当于 alpha 模块的“数据库”。

  跑起来
  - examples/veighna_trader：完整桌面客户端。
  - examples/no_ui：不要界面，最小化的连接+订阅+下单示例。
  - examples/cta_backtesting：vnpy/trader/optimize.py 做参数穷举/遗传算法优化。
  - 配置与运行时文件都在当前目录（或 ~/.vntrader）下的 vt_setting.json。

  一句话总结：事件引擎负责传话，Gateway 负责对外，OmsEngine 负责记账，App 负责策略，alpha 负责机器学习——你写的代码基本只落在 App/strategy 那一层
